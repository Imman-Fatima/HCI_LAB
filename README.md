# HCI_LAB
 MINI PROJECT
 
🌌 2D Solar System Animation Using Python Turtle

📌 Project Overview

This project is a 2D Solar System Animation developed using Python Turtle Graphics. It represents the Sun at the center and shows planets revolving around it in circular orbits.

The animation also includes the Moon revolving around the Earth, different planet sizes, orbit paths, and a starry background.

🎯 Project Objectives

- To understand basic 2D transformations.
- To demonstrate translation, rotation, and scaling.
- To create an animated Solar System using Python Turtle.
- To understand object movement and circular motion in computer graphics.

🛠️ Technologies Used

- Programming Language: Python
- Graphics Library: Turtle
- Math Library: Math
- Animation: Turtle Screen Update and Loops

🔄 2D Transformations Used

Transformation| Application
Translation| Planets change their positions along their orbits.
Rotation| Planets revolve around the Sun in circular paths.
Scaling| Different planet sizes demonstrate scaling.

🪐 Features

- Sun positioned at the center.
- Six animated planets: Mercury, Venus, Earth, Mars, Jupiter, and Saturn.
- Circular orbit paths for all planets.
- Moon revolving around Earth.
- Different colors and sizes for planets.
- Saturn's ring representation.
- Starry space background.
- Continuous animation.

💻 How to Run the Project

Step 1: Install Python on your computer.

Step 2: Clone this repository:

git clone https://github.com/your-username/solar-system-animation.git

Step 3: Open the project folder.

Step 4: Run the Python file:

python solar_system.py
